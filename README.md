# Josiah Prayer Suder — AI Automation Portfolio

Static GitHub Pages portfolio built with HTML, CSS, and vanilla JavaScript.

## Included
- Six project cards using the supplied workflow screenshots
- In-page project dialogs with embedded Loom walkthroughs
- Supplied profile portrait and resume PDF
- Responsive layout, readable typography, and reduced-motion support

## Deploy
Upload the contents of this folder to the existing repository root (not the outer ZIP folder). Keep GitHub Pages set to `main` / root.

## Local preview
Open `index.html` in a browser. Loom embeds require an internet connection and Loom sharing permission that allows visitors to view the video.
