# Josiah Prayer Suder — Portfolio Website

A responsive single-page portfolio built with HTML, CSS, and lightweight JavaScript. No framework or build step is required.

## Preview locally

Open `index.html` in a browser. Google Fonts require an internet connection; system fallback fonts are included.

## Before publishing

1. In `js/config.js`, add the real LinkedIn profile URL.
2. Add your final resume as `resume.pdf` in the root folder. The Resume links are hidden until `resume` is set to a non-empty value in `js/config.js`.
3. Replace the `JS` avatar placeholder with a real headshot if desired. Update the `.avatar` element in `index.html` and the `.avatar` styles in `css/style.css`.
4. Confirm the employment dates and edit them into `index.html` only after verification.
5. Verify which projects have live demos and which are architecture/portfolio builds. Do not claim production use or measurable outcomes without evidence.
6. Check all content and contact information before publishing.

## Deploy to GitHub Pages

Create a repository named `portfolio`, upload the contents of this folder to its root, then go to **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`.

A project repository normally publishes at `https://YOUR-USERNAME.github.io/portfolio/`. Your existing personal Pages repository `YOUR-USERNAME.github.io` publishes at the root domain. You can keep the new `portfolio` repository while preserving the existing root-site repository; choose the final URL intentionally before sharing it.
